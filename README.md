# Redemption Story — ressources FiveM

## `rs_english_campus` — English Campus

Plateforme d'apprentissage de l'anglais pour le serveur **Redemption Story School RP**. Elle fonctionne comme application du téléphone (**sd-phone**) et comme application de l'ordinateur (**rs_pc**), et s'appuie sur le **compte Campus** existant.

- Élèves : cours, exercices corrigés, évaluations chronométrées, notes, progression par compétence, révision du vocabulaire.
- Professeurs : éditeur de cours, évaluations, correction, carnet de notes, suivi en direct, messages aux classes.
- Administration : classes, rôles, statistiques, journal.

➡️ Installation, intégration Campus / sd-phone / rs_pc, sécurité et tests : voir [`rs_english_campus/README.md`](rs_english_campus/README.md).
